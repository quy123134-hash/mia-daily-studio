Mia Daily Studio

Mia Daily Studio is a personal content tool for creating short lifestyle vlog videos. Finished videos are sent to the creator's own TikTok account as drafts, so the creator can review them, add music and post them from the TikTok app.

The tool uses TikTok's official Login Kit and Content Posting API (upload to drafts). It does not publish anything automatically and does not access any other user's data.
